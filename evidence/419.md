# [abios-evidence] Issue #419 — fix: file-backed parameters for large inline payloads

## What was tested

Root cause (confirmed via field sweep, issue comments): the tool-layer path guard
pattern-matches the entire command string. Prose containing slash-commands (`/board`,
`/scan`, `/knowledge`, `/expert`) passed as inline parameters was interpreted as a
filesystem path reference and caused the whole command to abort — 65 confirmed failures
across 945 sessions (Board-Plan.ps1 at 30.3% failure rate, Board-Handoff.ps1 at ~22%).

The fix keeps large payloads off the command line entirely. Two changes:

1. `Board-Plan.ps1` — new `Resolve-TextParam` pure helper + `-DescriptionFile`,
   `-ResearchFile`, `-PriorArtFile` params. When a `*File` param is supplied the
   helper reads the file content and uses it; inline params remain for short text.
   File resolution happens BEFORE `Assert-PriorArtPresent` so the gate sees the
   file content.

2. `Board-Handoff.ps1` — new `Read-HandoffBodyFile` pure helper + `-BodyFile` param.
   The JSON file carries `NextStep`, `Done`, `OpenThreads`, `Traps`, `KeyFiles`. Sections
   absent from the JSON default to empty, and the corresponding inline param falls back
   to its default. Resolution happens after the dot-source guard, before any git/gh work.

Both helpers are in the pure section (behind the dot-source guard) and are fully
unit-tested without network or git access.

## Tests run

### Board-Plan targeted suite (7 new tests + 14 existing = 21)

**Command:**
```
pwsh -Command "Import-Module Pester; Invoke-Pester -Path 'plugins/agentic-board/tests/Board-Plan.Tests.ps1' -Output Detailed"
```

**Result:** Tests Passed: 21, Failed: 0

New tests (Resolve-TextParam):
- returns the inline value when filePath is empty ✅
- returns the inline value when filePath is whitespace-only ✅
- reads and returns file content when a valid file is provided ✅
- treats text containing slash-commands as data (not executed) when loaded from a file ✅
- a file with a destructive-looking command is returned as plain text, never executed ✅
- throws when the file path is set but the file does not exist ✅
- prefers the file when both a file and an inline value are supplied (file wins) ✅
